# Included aggregate tables

This directory deliberately contains only aggregate or quality-assurance outputs selected for a public code repository. It excludes row-level training, patient, sample, cell, and spot data, as well as restricted database derivatives and model objects.

Included table groups:

- drug-model aggregate performance, matched comparisons, runtime, and invariance checks;
- cross-assay aggregate cell-line performance;
- pathological-response aggregate internal and fixed-transfer performance;
- section-level spatial summaries and paired tests;
- aggregate survival effects, coefficients, and proportional-hazards diagnostics;
- network accounting summaries and scientific/release quality-assurance checks;
- assay/gene availability, missingness, and temporal eligibility summaries;
- corrected figure legends for provenance and terminology traceability.

The full internal audit archive remains with the authors and is not licensed for blanket public redistribution.
