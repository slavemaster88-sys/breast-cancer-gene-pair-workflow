# Reconstructed breast-cancer gene-pair workflow

This is the version **3.0.0 public-release package** for the manuscript **“Reconstruction and exploratory evaluation of rank-based tumour microenvironment-associated gene-pair scores in breast cancer.”** It contains author-developed analysis code, privacy-redacted provenance scripts, original figures, portable source manifests, and non-record-level summary results. It is not validated for clinical use.

Repository: https://github.com/slavemaster88-sys/breast-cancer-gene-pair-workflow

## Naming clarification

`SpaGI-BC` is retained only in historical paths, variables, and version identifiers as an internal project label. No verifiable formal expansion or corresponding published method was found. It is not the unrelated 2018 SPAGI method.

`sDDS` is retained only in legacy API and file names for computational traceability. The auditable output is a **predicted probability of the relative assay-defined sensitive class**, not a drug-effect estimate or a probability of patient benefit.

`DOP` in the source I-SPY2 study means **durvalumab–olaparib–paclitaxel**. Submission-facing text and figures use the full regimen name.

## Included

- `code/`: the R reconstruction workflow and privacy-redacted Python provenance scripts. The exact internal scripts remain hash-tracked in the authors' controlled audit archive.
- `figures/`: six author-generated manuscript figures in PNG/PDF form.
- `tables/`: aggregate performance, spatial-section, survival, and quality-assurance summaries listed in `tables/README.md`.
- `input_manifest_v3.csv`: portable `SOURCE_ROOT` locators, source-file sizes, and SHA-256 values; no machine-specific absolute paths.
- `external_source_manifest_v3.csv`, `figure_claim_manifest_v3.csv`, `parameters_v3.json`, `software_versions_v3.csv`, and `version_changes_v3.csv`. The figure-claim manifest explicitly marks whether each analysis-source table is included or retained only in the controlled internal archive.
- `table_index_public.csv`: dimensions, byte sizes, and SHA-256 values for the aggregate tables actually included here.
- `CITATION.cff`, provenance notes, third-party notices, and a self-excluding file hash manifest.
- `LICENSE.md`, `LICENSE-CODE`, and `LICENSE-CONTENT.md`: confirmed scope-based MIT and CC BY 4.0 licensing.

## Intentionally not included

The full internal archive contains third-party-derived or record-level outputs that should not be redistributed under a blanket repository licence. This public release therefore excludes:

- GDSC-derived response records, out-of-fold predictions, and frozen drug-model objects;
- KEGG or CellChat database copies and substantial pathway/ligand–receptor derivative tables;
- patient-, sample-, cell-, and spot-level tables;
- cBioPortal/METABRIC/TCGA record-level derivatives and sample manifests;
- public source datasets themselves.

These exclusions follow the source-specific review summarised in `THIRD_PARTY_NOTICES.md`. The code and portable manifests document how the full analysis was assembled, while accession numbers and official source links allow authorised retrieval.

## Figure 1 provenance

Figure 1 was generated by the authors' archived phase-1 workflow from public GSE176078 count matrices using Scanpy, Harmony, and infercnvpy, then carried forward unchanged into the present reconstruction. No panel was reproduced or adapted from Wu et al. The public copy of the phase-1 script externalises the 26-label subtype mapping; the exact executed script and mapping remain in the controlled internal audit archive. The authors have confirmed that the archived script and figure are their original work and were not previously published or licensed to a third party.

## Running the workflow

See `code/README.md` for the required directory structure, software versions, environment variables, and stage order. A full rerun requires the source files identified by `input_manifest_v3.csv` and must comply with each source's access terms. Frozen model objects are deliberately absent from this public-code release.
